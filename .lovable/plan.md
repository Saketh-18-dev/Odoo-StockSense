# StockSense frontend

## Build
- Create the shared responsive application shell with desktop and mobile navigation, top header, notifications, and profile controls.
- Establish the light indigo inventory design system and reusable controls for buttons, inputs, selects, tables, dialogs, badges, KPIs, headers, search, filters, empty/loading states, and toast feedback.
- Add complete mock-data screens for Dashboard, Products, Receipts, Delivery Orders, Internal Transfers, Inventory Adjustments, Move History, Warehouses, and Profile.
- Make navigation, filtering, search, product creation dialog, warehouse selection, menus, and profile editing feel functional without persistence.
- Add unique page metadata, responsive layouts, and polish across desktop and mobile.

## Technical details
- Keep the existing TanStack Start React/TypeScript foundation and Tailwind CSS v4 setup.
- Use route files for each shareable screen and reusable modules for the shell, UI primitives, mock data, and operation tables.
- Use only local component state and mock data; no backend, APIs, authentication, or database.
- Verify the preview, key interactions, mobile layout, and current build status.
